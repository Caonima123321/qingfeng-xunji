# 清风循迹 · 廉洁文化地图（微信小程序 + H5 网页 双版本）

一个把**四川省 21 个市州**的廉洁文化纪念场馆、教育基地落到地图上的小程序：
点开地图上的圆钉，就能看到家乡与廉洁相关的纪念馆、教育基地，读到背后的廉洁故事。

> 定位：为学校党员干部、师生群体及社会公众提供**可视化、可感知、可参与**的廉洁文化教育资源，打造"行走的廉洁课堂"。

---

## 〇、H5 网页版（手机浏览器直接打开，无需微信开发者工具）

`h5/` 目录是一套独立的纯静态网页应用（Leaflet + 高德瓦片），与小程序共用同一份点位库，手机浏览器直接访问即可。

**运行方式（推荐用服务端，支持多用户）**

```bash
node server/server.js 8090
```

- 本机打开 `http://127.0.0.1:8090/`；手机同一 WiFi 访问 `http://<电脑局域网IP>:8090/`。
- 服务端提供**用户注册/登录 + 每用户「循迹」云端同步**（见下方「多用户 + 公网部署」）。
- 只想本地纯静态预览（无登录、无同步）时，也可直接双击 `h5/index.html`。

**要点**

- 地图瓦片使用高德（gcj02 坐标系，与点位坐标直接对齐）；Leaflet 通过 CDN 加载，需联网。
- 功能与小程序端一致：地图圆钉 + 五类要素筛选 + 市州筛选 + 定位就近排序 + 一键回"家乡" + 详情（简介/看点/读史/名言/导航/电话/标记循迹）+ 搜索列表 + 关于页。
- **改了点位数据后**，运行 `node tools/build-h5.js` 重新生成 `h5/js/data.js` 再刷新页面。

## 〇·五、多用户 + 公网部署

**多用户**：`server/server.js` 是零依赖的 Node 服务端，同时托管 H5 静态页与 REST API：

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/register` | POST | 注册（用户名 + 密码，加盐散列存储，不明文） |
| `/api/login` | POST | 登录，返回 token |
| `/api/visited` | GET | 读取当前用户「循迹」列表（需 `Authorization: Bearer <token>`） |
| `/api/visited` | POST | 写入/取消某点位循迹（`{id, on}`） |

- 用户数据存 `server/data/users.json`（密码加盐散列）；会话在内存中，重启服务需重新登录。
- 前端：右上角 👤 按钮注册/登录；登录后「循迹」**跨设备云端同步**，换手机登录同一账号即可看到；不登录则本地保存（访客模式）。

**公网访问（不在局域网也能用）**，任选其一：

1. **云服务器**（最稳）：把整个项目传到任意装了 Node 的服务器，运行 `node server/server.js 80`，安全组放行 80 端口，用域名/公网 IP 访问。
2. **免费 Node 平台**：把项目推到 GitHub，在 Render / Railway / Fly.io 新建 Web Service，启动命令 `node server/server.js`，平台会给一个公网 `https://xxx.onrender.com` 地址。
3. **临时隧道**（免服务器、立即生效）：本机装 cloudflared 后运行 `cloudflared tunnel --url http://localhost:8090`，得到一个 `https://xxx.trycloudflare.com` 公网临时地址（无需账号，进程关掉即失效）。

## 三、快速开始

1. **打开工程**：微信开发者工具 → 导入项目 → 目录选择本目录（`D:\work\w`）→ AppID 选「测试号」即可预览。

## 四、怎么改成"你的"内容

### 1. 换"我的家乡"

只改一个地方 —— `data/constants.js`：

```js
const HOME = {
  city: '南充市',        // ★ 改成任意市州名，如 '广元市'、'眉山市'
  lat: 30.837332,        // 该市州（或家乡县城）中心坐标
  lng: 106.110244,
  label: '我的家乡 · 南充',
  desc: '川东北将帅故里，朱德故里、张澜故居、罗瑞卿故居皆汇于此'
};
```

地图页的「家乡」按钮、列表页的「我的家乡」页签、市州面板底部的一键回到家乡，都会自动跟随这个常量。

### 2. 增删点位

在 `data/sites.js` 的 `SITES` 数组里追加一条即可（地图 marker、列表、详情、统计会自动生效）：

```js
{
  id: 'guangyuan-xxx',            // 全局唯一，小写拼音短横线
  name: '某某廉洁文化教育基地',
  city: '广元市',                  // 必须是 constants.js 里 21 市州之一
  district: '利州区',
  address: '某某街道某某号',
  lat: 32.435435, lng: 105.843357,
  verify: 'verified',             // verified=已按官方地址核实；est=据地址估算
  categories: ['廉政教育', '家风家训'],   // 取值见五类要素
  tags: ['关键词', '便于搜索'],
  year: 2020,
  summary: '60-120 字简介……',
  highlights: ['看点一', '看点二'],
  story: '120-200 字廉洁故事/教育意涵……',
  quote: '相关名言、家训或对联',    // 可为 null
  phone: '0839-0000000',          // 可为 null
  official: false                 // 是否省级及以上官方命名基地
}
```

### 3. 改配色

全局主题变量在 `app.wxss` 的 `page { --c-primary … }`；圆钉颜色与图标在 `utils/site.js` 的 `PIN_MAP` 与 `data/constants.js` 的 `CATEGORIES`。改完分类颜色记得重新生成图标：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/gen-icons.ps1
```

### 4. 数据自检

```powershell
# 需 Node 环境（本机通过 DSH 内置运行时执行亦可）
node tools/check-data.js
```

输出点位数、21 市州覆盖情况、分类分布，以及 id 重复、坐标越界、分类非法等阻断性错误。

## 六、上架与内容合规建议

- **内容审核**：点位介绍与廉洁故事建议由学校纪检监察机构 + 宣传部门联合审核，再随版本发布；
- **表述规范**：历史人物与事件表述以官方史料为准，避免使用未经核实的坊间说法；
- **电话与开放时间**：属于易变信息，已在详情页标注"以场馆最新公告为准"，并建议在版本迭代中定期复核；
- **党建/研学场景**：可结合"标记循迹"功能做支部主题党日打卡统计，或按市州串联成"清风线路"（后续可在 `data/` 下新增 `routes.js` 扩展）。
